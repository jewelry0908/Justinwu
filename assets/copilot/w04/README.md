# W04 sample input pack

This pack contains five synthetic W04 inputs for the Delivery Intelligence Copilot portfolio demonstration.

The sources represent a project-system baseline, planning signals, development status and dependencies, UI/art/motion signals, and QA issues. Use the five images as one reporting input set. The workflow extracts and normalizes visible information, then routes conflicts, missing information, and internal-review signals through a confirmation gate before producing a report draft.

All W04 content is synthetic and intended for the public portfolio demonstration.
